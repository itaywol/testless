# testless Plan 1: Foundation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Cargo workspace with the language-agnostic graph core, TS + Go extraction (definitions, tests, imports), hash-gated cache, and a working `testless index` / `stats` CLI over fixture repos.

**Architecture:** `core` crate owns graph types, file discovery, parse orchestration, cache. `lang-ts`/`lang-go` implement the `Language` trait (tree-sitter grammar + extraction queries + import resolution). `cli` wires clap subcommands. No call/read edges yet (Plan 2), no diff/walk (Plans 3–4).

**Tech Stack:** Rust 2021, tree-sitter + tree-sitter-typescript + tree-sitter-go, clap (derive), serde + bincode, blake3, ignore, anyhow. Dev: assert_cmd, insta (snapshots), tempfile.

## Global Constraints

- Spec: `docs/superpowers/specs/2026-07-23-testless-design.md` — over-approximation principle governs every ambiguity: when unsure, record MORE (e.g. mark computed names, never drop a def).
- NixOS host: toolchain already installed (`cargo 1.96`). Never install imperatively; missing tool → `nix-shell -p <pkg> --run '...'`.
- Add dependencies with `cargo add <crate>` (resolves current versions); never hand-pin versions in the plan.
- TDD: every task = failing test first. Commit after every green step.
- Machine output on stdout, human chrome on stderr (matters from first CLI task).
- Fixture code lives in `fixtures/ts-app` and `fixtures/go-app`; they are DATA, excluded from workspace build.

```rust
use serde::{Deserialize, Serialize};
use std::path::PathBuf;

pub type NodeId = u32;
pub type FileId = u32;

#[derive(Debug, Clone, Copy, PartialEq, Eq, Serialize, Deserialize)]
pub enum DefKind { Function, Method, Class, TestCase, ModuleInit }

#[derive(Debug, Clone, Copy, PartialEq, Eq, Serialize, Deserialize)]
pub enum EdgeKind { Contains, Calls, Reads, Imports }

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct Def {
    pub name: String,
    pub kind: DefKind,
    pub file: FileId,
    pub start_line: u32,
    pub end_line: u32,
    pub test_id: Option<Vec<String>>,
    pub computed_name: bool,
}

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct FileNode { pub path: PathBuf, pub hash: [u8; 32], pub lang: String }

#[derive(Debug, Default, Serialize, Deserialize)]
pub struct Graph {
    pub files: Vec<FileNode>,
    pub defs: Vec<Def>,
    pub edges: Vec<(NodeId, EdgeKind, NodeId)>,
}

impl Graph {
    pub fn add_file(&mut self, f: FileNode) -> FileId {
        self.files.push(f);
        (self.files.len() - 1) as FileId
    }
    pub fn add_def(&mut self, d: Def) -> NodeId {
        self.defs.push(d);
        (self.defs.len() - 1) as NodeId
    }
    pub fn add_edge(&mut self, from: NodeId, kind: EdgeKind, to: NodeId) {
        self.edges.push((from, kind, to));
    }
    pub fn defs_in_file(&self, f: FileId) -> impl Iterator<Item = (NodeId, &Def)> {
        self.defs.iter().enumerate()
            .filter(move |(_, d)| d.file == f)
            .map(|(i, d)| (i as NodeId, d))
    }
    pub fn module_init(&self, f: FileId) -> Option<NodeId> {
        self.defs_in_file(f).find(|(_, d)| d.kind == DefKind::ModuleInit).map(|(i, _)| i)
    }
}
```
